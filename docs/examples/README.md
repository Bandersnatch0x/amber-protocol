# Examples

This directory contains real-project adoption artifacts.

Some files in this directory are preserved historical snapshots from earlier `harness.js`
runs. Treat those files as evidence artifacts, not as the current command reference. For
current usage, prefer the `node ../../scripts/amber.js ...` examples in this README and
start with read-only or `--dry-run` commands before approving any target write.

- `sample-adoption-walkthrough.md`: narrative walkthrough for a sample adoption trial.
- `sample-adoption-report.md`: fixed-path report generated with `adoption report --output`.
- `adoptions/`: timestamped reports generated with `adoption report --output-dir`.
- `adoptions-index.md`: markdown index generated with `adoption index --reports-dir adoptions --output adoptions-index.md`.
- `sample-adoption-diff.md`: markdown diff generated with `adoption compare --base ... --head ... --output sample-adoption-diff.md`.
- `sample-adoption-gate.md`: readiness gate generated with `adoption gate --reports-dir adoptions --output sample-adoption-gate.md`.
- `sample-adoption-status.md`: rollup generated with `adoption status --reports-dir adoptions --index adoptions-index.md --output sample-adoption-status.md`.
- `sample-adoption-bundle/`: review bundle generated with `adoption bundle --reports-dir adoptions --index adoptions-index.md --output-dir sample-adoption-bundle`.
- `sample-adoption-next-actions.md`: read-only gate-resolution checklist generated from a sample adoption bundle.
- `sample-adoption-next-actions-cli.md`: checklist generated by `adoption next-actions --bundle-dir sample-adoption-bundle --output sample-adoption-next-actions-cli.md`.
- `sample-adoption-decision-record.md`: pending Gate A/B/C audit record generated by `adoption decision-record --bundle-dir sample-adoption-bundle --output sample-adoption-decision-record.md`.
- `sample-adoption-decision-record-decisions.md`: Gate A/B/C record generated with explicit `--decision ...=deferred:...` notes.
- `sample-adoption-apply-plan.md`: dry-run bootstrap apply plan generated by `adoption apply-plan --bundle-dir sample-adoption-bundle --output sample-adoption-apply-plan.md --dry-run`.
- `sample-adoption-selected-files.md`: selected-files proposal generated by `adoption selected-files --bundle-dir sample-adoption-bundle --output sample-adoption-selected-files.md --include ...`.

Generated adoption reports are review artifacts. They do not imply that the target project was initialized, upgraded, or tested. `adoption list`, `adoption validate`, `adoption compare --reports-dir`, `adoption gate --reports-dir`, and `adoption status --reports-dir` are read-only. `adoption index`, `adoption compare --output`, `adoption gate --output`, and `adoption status --output` require explicit output paths that do not already exist. `adoption bundle --output-dir` also requires a directory that does not already exist and writes only the bundle directory. `adoption next-actions --output` writes only the requested checklist file and refuses to overwrite it. `adoption decision-record --output` writes only the requested decision record and refuses to overwrite it. Repeatable `--decision <gate>=<status>[:note]` flags record Gate A/B/C decisions but do not execute target writes or target commands. `adoption apply-plan --dry-run` writes only a review plan and refuses non-dry-run usage in V1. `adoption selected-files --output` writes only the requested proposal and repeatable `--include` values must be safe relative paths matching known Amber files.

Validate these artifacts with:

```sh
node ../../scripts/amber.js adoption validate --reports-dir adoptions --index adoptions-index.md
node ../../scripts/amber.js adoption compare --reports-dir adoptions
node ../../scripts/amber.js adoption gate --reports-dir adoptions
node ../../scripts/amber.js adoption status --reports-dir adoptions --index adoptions-index.md
node ../../scripts/amber.js adoption bundle --reports-dir adoptions --index adoptions-index.md --output-dir sample-adoption-bundle-review
node ../../scripts/amber.js adoption next-actions --bundle-dir sample-adoption-bundle --output sample-adoption-next-actions-review.md
node ../../scripts/amber.js adoption decision-record --bundle-dir sample-adoption-bundle --output sample-adoption-decision-record-review.md
node ../../scripts/amber.js adoption decision-record --bundle-dir sample-adoption-bundle --output sample-adoption-decision-record-decisions-review.md --decision command-confirmation=deferred:Need-owner-confirmation
node ../../scripts/amber.js adoption apply-plan --bundle-dir sample-adoption-bundle --output sample-adoption-apply-plan-review.md --dry-run
node ../../scripts/amber.js adoption selected-files --bundle-dir sample-adoption-bundle --output sample-adoption-selected-files-review.md --include AGENTS.md --include CLAUDE.md
```
