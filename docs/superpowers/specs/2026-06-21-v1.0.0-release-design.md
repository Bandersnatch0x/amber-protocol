## Milestone 5：自动发布流程（2-3 天）

### 5.1 配置 GitHub Secrets

在 GitHub 仓库设置中添加 `NPM_TOKEN`（Automation 类型）

### 5.2 CI 自动发布配置

在 `.github/workflows/ci.yml` 添加 `release` job：

```yaml
release:
  name: Publish to npm
  runs-on: ubuntu-latest
  needs: [test, web, coverage, security, performance]
  if: startsWith(github.ref, 'refs/tags/v') && !contains(github.ref, '-rc') && !contains(github.ref, '-beta')
  
  steps:
    - uses: actions/checkout@v6
    - uses: actions/setup-node@v6
      with:
        node-version: 22.x
        registry-url: 'https://registry.npmjs.org'
    - run: npm install
    
    - name: Validate package contents
      run: |
        npm pack --dry-run
        tar -tzf *.tgz > package-manifest.txt
        # 验证脚本...
    
    - name: Publish to npm
      run: npm publish
      env:
        NODE_AUTH_TOKEN: ${{ secrets.NPM_TOKEN }}
    
    - name: Create GitHub Release
      uses: actions/create-release@v1
      env:
        GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
      with:
        tag_name: ${{ github.ref }}
        release_name: Release ${{ github.ref_name }}
        body: See CHANGELOG.md for details.
```

### 5.3 测试自动发布
