## Highlights

1. **Policy dry-run no longer lies** — `governance rules check` uses the same built-in denies as execution (`evaluateGovernedPolicy`). Shell composites past a prefix allow are DENY; pure `2>&1` is allowed; default npm allow rule accepts `npm test 2>&1`.
2. **Evidence fidelity** — free-text feature evidence renders in handoff; audit/readiness count real `stage_completed` / `verification_failed` commands from dogfood sessions.
3. **Post-autonomous readiness** — `checkExecutionReadiness` keys off `rules.json`, not a missing root `autonomous-policy.json`.
4. **Web console** — timeline labels + command details for verify events; SSE `since` parses ISO timestamps; status shows `dirty (untracked only)`.
