# Packet A: V1 Backlog And Boundary Review

## Objective

Review the current Coding Harness project and produce a prioritized V1 backlog.

## Context

The product V1 is Safe Harness Bootstrap: `init`, `audit`, `wiki`, `doctor`, and `handoff`.

## Files / Sources

- `SPEC.md`
- `README.md`
- `ROADMAP.md`
- `scripts/`
- `templates/`
- `tests/`

## Ownership

Read-only review. Do not edit files.

## Do

- Group backlog as P0/P1/P2.
- Include rationale, acceptance criteria, and suggested implementation order.
- Flag any V1 overclaims.

## Do Not

- Propose product Dynamic Workflow execution for V1.
- Propose product subagent orchestration for V1.
- Propose automatic rewrite of old project files.

## Expected Output

Concise backlog and recommended next slice.

## Verification

Recommendations must trace back to current docs or tests.
