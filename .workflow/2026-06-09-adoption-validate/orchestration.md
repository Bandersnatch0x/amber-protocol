# Orchestration

1. Add failing CLI tests for report-directory validation and index-link validation.
2. Implement the smallest core helpers and CLI route needed to pass those tests.
3. Smoke-test against `docs/examples/adoptions` and `docs/examples/adoptions-index.md`.
4. Update docs with the read-only validation command.
5. Run full verification and close the workflow.
