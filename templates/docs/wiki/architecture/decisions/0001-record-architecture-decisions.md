# 0001 Record Architecture Decisions

## Status

Accepted

## Context

Architectural decisions should be stable, discoverable, and reviewable.

## Decision

Record meaningful architecture decisions in `docs/wiki/architecture/decisions/`.

## Consequences

- Agents can find prior decisions.
- New changes can reference existing constraints.
