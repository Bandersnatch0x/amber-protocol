# Clean State Checklist

Before ending a session, confirm:

- Standard verification command was run or the blocker is recorded.
- `feature_list.json` status matches the evidence.
- `PROGRESS.md` has current state and next action.
- `session-handoff.md` has enough context for a fresh agent.
- Temporary files, debug logs, and one-off scripts are removed or documented.
- Existing project documents were not overwritten without explicit human approval.
