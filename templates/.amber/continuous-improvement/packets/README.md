# Continuous Improvement Packets

Use this directory for isolated packet notes when a task needs research, synthesis, writing, or review roles.

Packets are planning and review artifacts. They do not grant permission to run dynamic workflows, dispatch subagents, or edit overlapping ownership areas.

## Packet Template

```text
Packet ID:
Role:
Objective:
Context:
Files / sources:
Ownership:
Do:
Do not:
Expected output:
Verification:
Status:
```

## Role Map

- Researcher: gather evidence, constraints, risks, prior decisions, and candidate approaches. Do not edit production files.
- Synthesizer: merge research into accepted facts, rejected assumptions, recommended approach, approval gates, and verification plan.
- Writer: implement one disjoint slice or write one concrete artifact.
- Reviewer: check the result against the objective, approval gates, existing patterns, and verification evidence.

When a packet is rejected, record the reason and loop only that packet.
